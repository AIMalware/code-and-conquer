LeetCode 424 — Longest Repeating Character Replacement
Problem Statement

You are given a string s consisting of uppercase English letters and an integer k.

You can choose at most k characters in the string and replace them with any uppercase English letter.

Return the length of the longest substring containing the same letter after performing at most k replacements.

Example

Input:

s = "ABAB"
k = 2

Output:

4

Explanation:

Replace the two 'A' characters with 'B' (or vice versa):

"BBBB"

Longest valid substring length is:

4
Approach — Sliding Window
Main Idea

We maintain a sliding window where:

(window size - frequency of most common character) <= k

Why?

The most frequent character can remain unchanged.
All other characters in the window must be replaced.
If replacements needed are within k, the window is valid.
Step-by-Step Explanation
Variables
left = 0

Left pointer of the sliding window.

count = {}

Stores frequency of characters inside the current window.

ans = 0

Stores the maximum valid window length.

maxFrequency = 0

Stores the frequency of the most repeated character in the current window.

Expanding the Window
for right in range(len(s)):

right is the right pointer of the window.

Add current character frequency:

count[s[right]] = count.get(s[right], 0) + 1

Update maximum frequency:

maxFrequency = max(maxFrequency, count[s[right]])
Calculate Replacements Needed

Window size:

window = right - left + 1

Characters to replace:

replacementNeeded = window - maxFrequency

Because:

maxFrequency characters are already same.
Remaining characters must be replaced.
Shrink Window if Invalid

If replacements exceed k:

if replacementNeeded > k:

Remove left character from frequency map:

count[s[left]] -= 1

Move left pointer:

left += 1
Update Answer

Store maximum valid window size:

ans = max(ans, right - left + 1)
Dry Run

Input:

s = "AABABBA"
k = 1
Window	Max Frequency	Replacements Needed	Valid
A	1	0	Yes
AA	2	0	Yes
AAB	2	1	Yes
AABA	3	1	Yes
AABAB	3	2	No

Maximum valid length:

4
Code
class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        left = 0
        count = {}
        ans = 0
        maxFrequency = 0
        
        for right in range(len(s)):
            count[s[right]] = count.get(s[right], 0) + 1

            maxFrequency = max(maxFrequency, count[s[right]])

            window = right - left + 1

            replacementNeeded = window - maxFrequency

            if replacementNeeded > k:
                count[s[left]] -= 1
                left += 1

            ans = max(ans, right - left + 1)

        return ans
Time Complexity
O(n)

Each character is visited at most twice.

Space Complexity
O(1)

At most 26 uppercase letters are stored in the hashmap.
